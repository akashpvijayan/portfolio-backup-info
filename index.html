Personal backup utility

Portfolio Assistant Backups

A personal utility for keeping encrypted copies of Portfolio Assistant records in the owner's Google Drive and checking that those copies can be recovered.

Operated by Akash P Vijayan for his own account. This website provides app information; Google authorization is completed separately during the utility's setup.

What the utility is for

The backup workflow creates a copy of the application's database with a corresponding journal checkpoint, encrypts the backup before transfer, and uses Google Drive to store and retrieve the encrypted copy. Integrity checks and recovery checks help the owner assess whether a backup is usable.

Why Google Drive access is requested

The utility requests the drive.file permission. This lets it create and work with files it creates, or files the owner explicitly authorizes for this app. It does not request general access to every file in the owner's Drive.

Drive access supports uploading encrypted backups, retrieving them for verification or recovery, and reading the metadata needed to identify them. Backup contents and Google authorization credentials are kept outside this information website.

Who can use it

This is a personal utility, with no public registration or commercial backup service. It has no authority to place trades. Backup scheduling is configured separately; publishing this website does not enable a backup schedule.

Privacy and contact

Read the privacy policy for details about data access, storage, retention and revocation. For app or privacy questions, use the user support email displayed on the Google permission screen for Portfolio Assistant Backups.
